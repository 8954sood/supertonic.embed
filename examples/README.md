# Example references

Five speakers from the Common Voice subset of [Seed-TTS Eval](https://github.com/BytedanceSpeech/seed-tts-eval), used here so the extractor can be tried without downloading a corpus. Common Voice recordings are released under CC0, a public domain dedication.

Each file is two Common Voice clips from one speaker, concatenated, which is how Seed-TTS Eval distributes them.
